# Supplementary Figures

This directory contains result figures that are not included in the main paper due to space constraints.

- `ranking_beir/`: Full-cross role-play ranking results on BEIR-style SciFact, TREC-COVID, FIQA, and Climate-FEVER settings across Llama, Mistral, and Qwen.
- `patching_head_maps/`: Head-level patching maps for DL19 and DL20 across Llama, Mistral, and Qwen.
